# Vue 商品列表：computed 搜索、筛选和排序

这是一个独立的 Vue 3 学习 Demo，用三条演示商品理解：如何保留完整数据，再根据搜索词、素材条件和排序方式计算页面展示结果。

## 功能与学习目标

- 搜索商品名称、描述和卖点；按是否有素材筛选；按名称或更新时间排序。
- 组合多个条件，查看结果数量、空状态及重置效果。
- 展开原始数据，观察筛选、排序后完整列表是否发生变化。
- 理解 `ref`、`computed`、`v-model`、`v-for` 之间的数据流，以及 `filter` 和 `sort` 对数组的影响。

示例数据全部写在页面里，不调用后端，不保存编辑结果。

## 环境与启动

需要 Node.js 和 npm，用于安装 Vue 依赖。在本目录执行：

```bash
npm install
```

安装完成后，用浏览器打开本目录的 `index.html`。页面从本 Demo 的 `node_modules` 加载 Vue，无需业务项目或开发服务器。首次安装依赖需要网络；不要将 `node_modules` 提交到 Git。

## 精读顺序

核心代码都在 `index.html`。先看下半部分 `setup()`，按注释读第 1、2、3 步：

1. `products` 保存三件完整商品。
2. `search`、`materialFilter`、`sort` 分别保存三个条件。
3. `filteredProducts` 先 `filter`，再对筛选结果 `sort`。

再回到模板，看第 4、5 步：`v-model` 修改条件，`v-for` 展示计算结果。这里使用 Vue 浏览器版本和普通 HTML 模板，因此 `setup` 需要显式 `return` 模板要用的变量；Vue 单文件组件的 `<script setup>` 不需要这一步。

可以试着搜索“保湿”：植物精华的描述和身体乳的卖点都会匹配；再选“有素材”，只显示身体乳。重置后恢复三件商品。

## 关键原理与取舍

控件修改的是条件；`computed` 根据完整列表和当前条件推导展示列表，不需要分别在每个控件事件里手动刷新列表。`filter` 创建新数组，随后 `sort` 修改这个新数组，因此原列表的顺序不变。不过新数组里的商品对象仍是原对象；本例只读取这些对象，不修改商品字段。

为方便专注前端数据流，本例省略了分页、服务端筛选、接口错误处理与商品保存，也没有使用业务项目内部模块。
